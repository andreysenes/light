# ZS-040 — Bluetooth MIDI (Medusa)

O **ZS-040** (clone **HM-10** / BLE UART) é o módulo de **conexão sem fio** oficial do StageMod v0, montado na [**Medusa**](17-CABECA-MEDUSA.md) junto do Pro Micro.

## Função no projeto

| Caminho | Hardware |
|---------|----------|
| **Palco** (sem cabo USB) | DAW → Bluetooth → **ZS-040** → **Serial1** → Pro Micro |
| **Ensaio** (cabeça perto) | DAW → **USB** → Pro Micro (mesmo firmware) |

Firmware: `ENABLE_SERIAL_MIDI 1` em [promicro-4mod.ino](../firmware/promicro-4mod/promicro-4mod.ino).

## Pinagem típica do módulo

Confirme no silk da sua placa (nomes variam):

| Pino ZS-040 | Ligação Medusa |
|-------------|----------------|
| **VCC** | **5 V** (se breakout permitir) ou **3,3 V** (AMS1117) |
| **GND** | GND comum |
| **TX** | Pro Micro **RX** — **D0** / **Serial1** |
| **RX** | Pro Micro **TX** — **D1** (divisor 5 V→3,3 V se necessário) |

```
Pro Micro (5V)                    ZS-040
    D0 RX ◄────────────────────── TX
    D1 TX ──[1k]──┬──────────────► RX
                  │
                 [2k]
                  │
                 GND
    5V ───────────────► VCC (ou 3V3)
    GND ──────────────► GND
```

## Configuração AT (uma vez)

Adaptador USB-UART, terminal **9600** 8N1, comandos terminados com `\r\n`:

| Comando | Função |
|---------|--------|
| `AT` | Responde `OK` |
| `AT+BAUD4` | UART **115200** (igual ao firmware) |
| `AT+NAMEStageMod` | Nome visível no Bluetooth (opcional) |
| `AT+ROLE0` | Periférico BLE (padrão em muitos clones) |

Depois do `AT+BAUD4`, ajuste o terminal e o [bridge no PC](18-WIRELESS-MIDI.md) para **115200**.

## No PC

1. Parear **ZS-040** (Bluetooth do sistema).
2. Abrir porta **COM** criada.
3. Bridge **MIDI → serial** (ex. Hairless MIDI Serial) @ **115200**.
4. DAW → porta MIDI virtual do bridge.

Não enviar MIDI **ao mesmo tempo** pela USB e pelo BT.
